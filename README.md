# FZR塔防自动化脚本

## 项目介绍

FZR塔防是一个基于Python+YOLO模型的自动化脚本项目，用于在指定窗口中识别特定的图形或标识，并执行相应的键鼠操作。

### 项目功能

1. **目标识别**：使用YOLO模型在指定窗口中识别特定的图形或标识
2. **键鼠操作**：根据识别结果执行相应的键鼠操作
3. **脚本录制**：内置键鼠操作录制工具，可记录开发者的键鼠操作并转换为Python代码
4. **模块化设计**：采用模块化架构，便于扩展和维护

## 项目结构

```
├── src/                 # 主源码目录
│   ├── scripts/         # 键鼠操作子脚本目录
│   ├── recorder/        # 键鼠操作录制工具
│   ├── core/            # 核心模块
│   ├── models/          # YOLO模型目录
│   ├── config/          # 配置文件目录
│   └── main.py          # 主脚本文件
├── data/                # 数据目录
├── logs/                # 日志目录
├── tests/               # 测试目录
├── requirements.txt     # 依赖文件
└── README.md            # 项目说明
```

## 安装说明

### 1. 克隆项目

```bash
git clone <项目地址>
cd 视觉脚本
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 下载YOLO模型

默认使用YOLOv8n模型，会在首次运行时自动下载。

## 使用方法

### 1. 录制键鼠操作

```bash
python -m src.recorder.recorder
```

- 按ESC键停止录制
- 录制完成后会提示输入脚本名称
- 生成的脚本会保存到 `src/scripts/` 目录

### 2. 运行主脚本

```bash
python -m src.main
```

主脚本会：
- 查找指定窗口（默认标题："FZR塔防"）
- 激活窗口并获取窗口区域
- 截图并进行目标检测
- 根据检测结果调用相应的键鼠操作脚本

### 3. 自定义键鼠操作脚本

1. 在 `src/scripts/` 目录创建新的Python文件
2. 参考 `template.py` 模板编写脚本
3. 确保脚本函数名与文件名一致
4. 实现 `params` 参数接收和结果返回

## 配置说明

配置文件位于 `src/config/config.py`，可根据需要修改：

- `WINDOW_TITLE`：目标窗口标题
- `YOLO_MODEL_PATH`：YOLO模型路径
- `CONFIDENCE_THRESHOLD`：置信度阈值
- `SCRIPT_TIMEOUT`：脚本执行超时时间

## 开发指南

### 1. 添加新的目标检测

1. 准备训练数据
2. 训练YOLO模型
3. 将模型放置到 `src/models/` 目录
4. 修改配置文件中的模型路径

### 2. 添加新的键鼠操作脚本

1. 使用录制工具录制操作
2. 或参考模板手动编写脚本
3. 将脚本保存到 `src/scripts/` 目录
4. 在 `main.py` 的 `get_script_for_detection` 方法中添加映射关系

## 注意事项

1. 确保目标窗口存在且可见
2. 避免在脚本运行时手动操作鼠标和键盘
3. 首次运行时会下载YOLO模型，可能需要一些时间
4. 录制的脚本可能需要根据实际情况进行调整

## 故障排除

### 常见问题

1. **找不到窗口**：检查窗口标题是否正确，确保窗口已打开
2. **检测失败**：检查模型是否正确，调整置信度阈值
3. **脚本执行失败**：检查脚本语法是否正确，查看日志文件

### 日志

日志文件位于 `logs/main.log`，可查看详细的运行信息和错误信息。
